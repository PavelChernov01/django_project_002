О проекте Task Manager

Описание проекта

Task Manager - это веб-приложение для управления задачами, проектами и комментариями.

Возможности:

  • Управление задачами (создание, редактирование, удаление)
  • Назначение исполнителей
  • Добавление комментариев к задачам
  • Загрузка вложений
  • Фильтрация и пагинация задач
  • Управление проектами

Технологии:

  • Django 6.0.4
  • PostgreSQL
  • Bootstrap 5
  • Django Debug Toolbar
